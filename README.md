# Лавка — свой «Авито»

Всё бесплатно. Объявления, фото и переписки лежат на твоём компе (SQLite + папка `uploads`).

```
lavka/
  server/    Flask-сервер: API + сайт (static/) + Telegram-бот
  android/   приложение Kotlin + Compose, ходит в тот же API
```

## 1. Сервер

Нужен Python 3.9+ и Flask (`pip install flask`). Больше ничего.

```bash
cd server
python app.py
```

Сайт: `http://localhost:8080`. Данные: `server/data/` (`lavka.db` + `uploads/`) — это и есть бэкап, копируй папку.

Переменные окружения (все необязательные):

| Переменная | Что делает |
|---|---|
| `LAVKA_PORT` | порт, по умолчанию 8080 |
| `LAVKA_DATA` | куда складывать базу и фото |
| `LAVKA_TG_TOKEN` | токен бота — включает Telegram-уведомления |
| `LAVKA_TG_PROXY` | http-прокси для Telegram, если он у тебя блокируется |
| `LAVKA_PUBLIC_URL` | адрес сайта для ссылки в уведомлении |

Windows: `set LAVKA_TG_TOKEN=...` перед `python app.py`. Linux: `LAVKA_TG_TOKEN=... python3 app.py`.

**Доступ из локалки.** Узнай IP компа (`ipconfig` / `ip a`), например `192.168.1.50`. Открой порт 8080 в брандмауэре Windows. Сайт будет на `http://192.168.1.50:8080` с любого устройства в этой Wi-Fi.

**Для продакшена** (когда выведешь в интернет) вместо `app.run` запускай через waitress: `pip install waitress`, `waitress-serve --port=8080 app:app`. Наружу — через Cloudflare Tunnel (без белого IP), тогда будет и HTTPS.

## 2. Telegram-бот

1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Запусти сервер с `LAVKA_TG_TOKEN`.
3. В Лавке: Профиль → Telegram → «Привязать» → откроется бот, нажми Start.
4. Теперь каждое новое сообщение в чате прилетает в Telegram. Отвязать: `/stop` боту или кнопка в профиле.

## 3. Вход по своему ID

При регистрации сервер выдаёт ID вида `L-K7QM-4XZP`. Вход: ID + пароль. Почта и телефон не нужны. Пароль хранится как PBKDF2-хеш, токены — как SHA-256, после 8 неверных попыток вход блокируется на 5 минут.
**Восстановления нет**: потерял ID — потерял аккаунт.

## 4. Android

1. Открой папку `android/` в Android Studio (Ladybug или новее), дождись синхронизации Gradle.
2. Run на телефоне или эмуляторе (или Build → Build APK).
3. В приложении → Профиль → внизу «Адрес сервера», например `http://192.168.1.50:8080`. Телефон должен быть в той же Wi-Fi.

Приложение работает по http (для локалки это включено). Когда выведешь сервер на HTTPS, в `AndroidManifest.xml` убери `usesCleartextTraffic`, а в `network_security_config.xml` поставь `false`.

> Android-часть я не компилировал: в моём окружении нет Android SDK. Код написан аккуратно, но при первой сборке возможны мелкие ошибки — кидай текст ошибки, поправлю.

## Что умеет

- Объявления с фото (до 8), категории, цена или «бесплатно», город
- Поиск без учёта регистра (в т.ч. кириллица), фильтры: категория, цена, город, бесплатно, сортировка
- Избранное, «продано», удаление, страница продавца
- Чаты покупатель ↔ продавец, счётчик непрочитанных
- Telegram-уведомления о сообщениях
- Сайт адаптивный, тёмная тема по системной настройке
